# 文苑文学社 · 平台更新公告

**发布 2026-08-11**

各位文苑的朋友：

这期更新，我们把「作者与读者、读者与读者」之间的联结做得更近了一步：可以关注喜欢的作者、收藏心动的作品、给评论和作品点赞，而每一次这样的动静，都会收进一个干净的「消息」里，等你回来时再看。

---

## 本次更新内容

1. **关注作者**
   在作者主页或作品页点「**关注**」，这位作者的动态就会常驻在你的「**我关注的人**」里。以后想找哪位作者的新作，不用再满站翻。

2. **收藏作品**
   读到想留着慢慢品的作品，点作品页的「**收藏**」放进自己的「**我的收藏**」，随时回来重读。

3. **评论点赞与作品喜欢**
   觉得一条评论说到心坎里、或者喜欢一篇作品，都可以点赞。你的每一次认可，作者和评论者都能在消息里看到。

4. **站内通知**
   评论、回复、点赞、关注、收藏……这些动静不再散落各处，而是集中到页面顶部的「**消息**」里：有未读时会出现数字角标，点开即可查看，也支持一键「**全部已读**」。

---

## 使用小提示

- 登录后，通过页面顶部的账户菜单进入「我的关注 / 我的收藏 / 关注我的人」。
- 未读的消息会在「消息」入口和移动端底栏显示数字角标，点开后自动标记已读。
- 如果打开页面还是旧版，请**强制刷新**（Windows / Linux：`Ctrl+F5`，macOS：`Cmd+Shift+R`），或改用无痕窗口查看。
