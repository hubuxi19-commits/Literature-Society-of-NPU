# 移动端分类搜索合并栏设计

## 目标

把移动首页现有的横向分类栏与折叠搜索区合并成一条紧凑工具栏，减少页面纵向占用，让稿页更早进入视野。只调整宽度不超过 760px 的移动端，桌面端保持不变。

## 布局

工具栏固定为单行三段：

`[ 当前分类 ▾ ] [ 搜索作品输入框 ] [ 搜索 ]`

- 左侧分类按钮默认显示“全部”，高度不小于 44px。
- 中间输入框占据剩余宽度，提示文字为“搜索作品”。
- 右侧保留独立“搜索”按钮，高度不小于 44px。
- 移除移动首页现有的横向分类按钮条和带“＋”号的折叠搜索区。

## 分类交互

- 点击左侧按钮后，在工具栏下方展开分类菜单。
- 菜单包含现有全部分类：全部、新诗、旧诗、散文、小说、随笔、其他。
- 当前分类使用暗红色标记，并设置可访问状态。
- 选择分类后立即执行筛选、更新左侧按钮文字，并自动收起菜单。
- 再次点击分类按钮或点击工具栏外部时关闭菜单。

## 搜索交互

- 输入关键词本身不发起请求，避免打字时反复刷新稿页。
- 点击右侧“搜索”按钮或在输入框按回车后执行搜索。
- 搜索时保留当前分类条件；分类筛选与关键词搜索可以组合。
- 清空输入框后点击“搜索”恢复当前分类下的全部作品。

## 视觉与状态

- 延续现有纸张、细边线、宋体/仿宋和暗红色强调，不引入新视觉体系。
- 分类菜单从工具栏下方自然展开，不使用全屏弹窗，也不遮挡底部导航。
- 请求期间保留当前稿页，沿用已有顶部 2px 进度反馈，不显示“正在整理稿页”。
- 小屏宽度下分类按钮和搜索按钮保持内容宽度，输入框允许收缩但不得造成横向溢出。

## 实现边界

- 复用现有 `state.filters`、`setFilters` 与 `loadBrowseWorks` 数据流。
- 新增一个移动端合并栏渲染函数及菜单开关行为；不修改数据库和 RPC。
- 删除移动端旧分类横条与折叠搜索组件的调用，桌面筛选表单不变。

## 验证

- 单元/静态检查：移动首页只渲染一个合并栏；分类列表完整；旧横条和折叠区不再出现。
- 390×844 浏览器检查：工具栏无横向溢出，三段控件均可见且触控高度不少于 44px。
- 行为检查：打开/关闭分类菜单、选择分类后收起、分类与关键词组合搜索、回车搜索、返回首页状态保留。
- 完整回归：运行项目单元/数据库测试及桌面、移动浏览器流程。
