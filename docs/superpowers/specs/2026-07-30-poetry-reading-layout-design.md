# 诗歌阅读排版修订设计

## 目标

作品阅读页根据体裁采用不同的正文排版。诗歌必须尊重作者输入的诗行和分节，不再套用小说式的首字装饰；其他体裁维持当前长文阅读体验。

## 排版规则

### 诗歌

- 作者输入的一次换行对应阅读页中的下一诗行。
- 连续两次或更多换行表示新诗节，诗节之间显示比普通诗行更大的垂直留白。
- 正文不使用首行缩进。
- 第一字不放大、不变色、不浮动。
- 桌面端和移动端均保留相同的诗行与分节结构。

### 非诗歌

- 小说、散文、随笔和其他分类继续按空白行拆分段落。
- 保留现有段落缩进。
- 保留当前第一段首字装饰。

## 实现边界

- 阅读页渲染函数接收作品内容和分类，根据分类生成带体裁类名的正文区域。
- 诗歌仍按诗节生成段落节点，每个诗节内部保留单次换行；不将每一诗行转换为独立段落。
- 使用体裁限定的 CSS 选择器，确保首字装饰只作用于非诗歌正文。
- 不修改数据库表、RLS、作品内容存储格式或 Supabase 配置。
- 不自动重写已经发布的作品内容；展示层忠实使用数据库中保存的换行。

## 验证

- 自动化测试验证诗歌正文保留单次换行、分节结构和诗歌专用类名。
- 自动化测试验证诗歌没有首字放大或段落缩进。
- 自动化测试验证小说仍按段落显示并保留现有首字装饰。
- 在桌面端和移动端打开诗歌阅读页，检查诗行、分节间距、横向溢出和控制台错误。
