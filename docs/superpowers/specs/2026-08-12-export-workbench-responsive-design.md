# 导出工作台中等宽度响应式设计

## 问题

导出工作台只在 760px 以下切换为单栏。约 920px 至 1099px 的电脑窗口仍使用双栏，导致设置和预览同时被压缩、稿页过窄、底部操作不易看全。

## 方案

- 1100px 及以上保留左右双栏，设置区约 40%，预览区约 60%。
- 761px 至 1099px 改为上下布局：设置区在上，预览区在下；设置项使用多列排布。
- 760px 及以下继续使用手机单栏布局。
- 电脑端弹窗同时允许纵向与横向滚动；当浏览器缩放或可用宽度不足时，底部显示可拖动的横向滚动条作为兜底。
- 手机端继续使用单栏，不显示横向滚动条。
- 底部“取消 / 生成图片”操作栏固定在工作台可视区域底部。
- 预览保持 1080×1920 比例并水平居中。

## 验证

- 920px 视口底部存在可拖动的横向滚动条，能够访问被裁区域；1024px 视口保持舒适布局。
- 1440px 视口保留双栏布局。
- 现有手机与桌面导出、分页和保存流程继续通过。
