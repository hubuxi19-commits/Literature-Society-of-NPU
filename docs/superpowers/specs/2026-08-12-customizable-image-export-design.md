# 可调整作品图片导出工作台设计

## 目标

把现有“一键生成作品图片”升级为居中的导出排版工作台。用户无需设置即可使用推荐的通用素笺模板生成图片，也可以在生成前调整常用排版参数。输出继续保持 1080×1920 PNG，并根据正文长度与排版参数自动分页。

## 入口与工作台

点击作品页“生成作品图片”后，不再立即编码 PNG，而是打开居中排版工作台。桌面端采用设置与预览双栏，移动端自然变为上下排列。工作台含页数、关闭、上一页/下一页、恢复通用模板和生成图片操作；关闭后不改变阅读页。

## 通用素笺模板

首次使用自动应用：宋体、36px、居左、1.9 行距、标准页边距、显示标题与作者、米白素笺、1080×1920 PNG 自动分页。标题与作者共用一个显示开关。

## 可调整设置

- 字体：宋体、仿宋、楷体、黑体。
- 正文字号：28–52px，以 2px 为步长。
- 对齐：居左、居中、居右。
- 行距：1.5、1.7、1.9、2.1。
- 页边距：紧凑、标准、宽松。
- 标题与作者：同步显示或隐藏。
- 纸张：素笺、纯白、宣纸浅纹。

第一版不加入自由拖动、上传字体、任意背景图、滤镜或逐页独立排版。

## 预览与生成

设置改变时重新测量内容、计算页数，并用与最终导出相同的 HTML 页面 DOM 缩放成轻量预览，不创建 Blob 或编码 PNG。只有点击“生成图片”才执行高清导出。结果继续支持分享全部、保存全部、逐页保存和逐页预览。生成过程中禁用重复提交；设置变化后旧高清结果失效。

## 自动分页

- 字号、行距、边距、标题显示或字体变化后重新分页。
- 诗歌不拆分正常诗行并保留空行。
- 散文优先在段落边界分页；单个段落超过一页时才按字符边界拆分。
- 每页编码前检查整页及正文溢出，不能丢字、重复或截断。
- 单行在最大正文区域仍无法容纳时，提示减小字号或边距。

## 设置保存

设置以带版本号的对象保存在当前设备 `localStorage`。字段缺失、越界、损坏或版本不兼容时回退通用模板。“恢复通用模板”立即重置、更新预览并覆盖本机值。配置不进入数据库。

## 技术与异常边界

- 扩展现有 HTML/CSS 页面导出器，不改为 Canvas 手工排版。
- 同一规范化配置对象驱动分页、预览与最终 PNG。
- 字体不可用时由 CSS 字体栈回退宋体；设置损坏时恢复默认。
- 关闭工作台或切换作品时清理临时预览和 Blob URL。
- 分享不受支持时仍保留保存全部及逐页保存。
- 不修改数据库、Supabase RPC、作品正文或公开作品数据。

## 验证

- 短文单页、长文多页；诗行不拆，散文不丢字。
- 极端字号、四档行距与三档边距可安全分页。
- 三种对齐、三类纸张、标题作者开关和四种字体在预览与 PNG 中一致。
- 设置跨页面保留且可恢复默认。
- 手机与桌面无横向溢出，控件高度不小于 44px。
- 单元、数据库、桌面和移动浏览器回归通过。
